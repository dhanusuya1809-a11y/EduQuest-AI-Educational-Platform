# EduQuest – AI-Assisted Educational Platform

## 🌐 Live Website

[Visit EduQuest](https://my-site-zn1h539s-dhanusuya1809.wix-vibe-site.com/)

## 📌 Project Overview

EduQuest is an AI-assisted educational web platform designed to provide
a simple and student-friendly learning experience.

The website was created using Wix Vibe with Generative AI-assisted
development and UI/UX design principles.

## ✨ Key Features

- Student-friendly user interface
- Simple and intuitive navigation
- Educational content structure
- Responsive web design
- AI-assisted website development
- Clean and modern UI/UX

## 🛠️ Tools & Technologies

- Wix Vibe
- Generative AI
- UI/UX Design
- Figma
- Adobe Photoshop
- AI-assisted Web Development

## 👩‍💻 My Contribution

I worked on the project concept, design direction, feature requirements,
content structure and refinement of the AI-generated website.

I used Generative AI and Wix Vibe to explore ideas and build the
educational platform.

## 🎯 Project Objective

The objective of EduQuest is to create an accessible and
student-friendly digital learning platform while demonstrating the
practical use of Generative AI in web development and UI/UX design.
